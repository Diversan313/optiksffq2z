# optiksffq2z

### Назначение проекта

Это небольшой Python-скрипт запускаемый через GitHub Actions, который автоматизирует продление доступа к серверу на панели OptikLink (control.optiklink.net).

### Скрипт с помощью Playwright:

1. Авторизуется в Discord, подставляя пользовательский токен в localStorage;
2. Проходит OAuth-авторизацию на optiklink.net и подтверждает её нажатием кнопки «Authorize», тем самым продлевая 3-дневный таймер сервера;
3. Проверяет по содержимому Dashboard, что авторизация прошла успешно;
При наличии API-ключа Pterodactyl отправляет запрос на запуск сервера (power: start), если он был выключен, с несколькими повторными попытками при таймаутах панели.

Это автопилот для абуза, чтобы бесплатный сервер не засыпал из-за отсутствия ручного захода на сайт более 3 дней.

### Как пользоваться

Секреты репозитория (Settings → Secrets and variables → Actions) — добавить:

1. DISCORD_TOKEN — обязателен, токен Discord-аккаунта, к которому привязан сервер;
2. PTERO_API_KEY —  ключ клиентского API Pterodactyl, нужен для автозапуска остановленного сервера;
3. SERVER_ID — ID сервера из панели, лучше добавить.

Запуск: workflow в .github/workflows рассчитан на регулярный автоматический запуск по расписанию (cron), плюс его можно запустить вручную через вкладку Actions → «Run workflow».

### Важное замечание

Подстановка токена аккаунта в localStorage для автоматической авторизации формально относится к автоматизации входа без пароля через сессионный токен — Discord расценивает такие действия (self-bot-подобная автоматизация клиента) как нарушение ToS, что теоретически может привести к ограничению аккаунта. Стоит держать это в уме при регулярном использовании.
